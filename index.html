What you can do

One section on the Home screen, the full lifecycle behind it. Real screenshots from the Twind mobile app (release demo).

View & search

A dedicated Temporary Authorizations section on the Home screen lists Active and Scheduled authorizations for the current site, ordered by soonest to expire.

  • Search bar filters by any content in the list.
  • Each item shows: name, value (Temporarily allowed / not allowed), status, resource, dates and contractor.
  • Expired and deleted items are hidden by default — toggle "Show expired and deleted authorizations" to include them.
Active Scheduled Expired Deleted

Create

New TA from the Home section header or from the Resource Details screen, with the + Add action.

  • Same mandatory fields as web: name, authorizer (pre-filled), contractor, resource type & name, site (pre-filled), value (Allowed / Not allowed), dates and reason.
  • Same validation rules — including no overlapping TAs for the same resource and site.
  • On save, access status updates immediately and the TA appears in the Home listing.
TA Manager · Client Admin

Edit

Inline editing from the TA detail panel, for Active, Scheduled and Expired authorizations. Deleted ones cannot be edited.

  • All fields editable — including the authorizer.
  • Same validation rules as the web platform.
  • Changes reflect instantly in access status and the Home listing.
  • Web notifications for TA edits trigger as usual.
TA Manager · Client Admin

Delete

Available from the TA detail panel for Active, Scheduled and Expired authorizations.

  • Confirmation dialog before any action is taken.
  • On confirm, the TA is marked Deleted and standard access control is restored immediately for all affected resources.
  • The historical record is kept for audit purposes.
  • Web notifications for TA deletions trigger as usual.
TA Manager · Client Admin

Changelog & audit trail

Every TA accessible from the app includes a full, read-only changelog.

  • Who created or modified it, when, and what action was performed.
  • Available across all statuses: Active, Scheduled, Expired and Deleted.
  • Accessible to every role that can view TA detail.
  • App actions are recorded with origin APP, user and timestamp.

⚠️ Local Mode limitation

Create, edit and delete are not available in Local Mode. Actions are disabled with the tooltip: "Local mode must be disabled to … Temporary Authorizations." Viewing remains available.

Quick answers

What exactly is a Temporary Authorization?
A mechanism to punctually override the calculated access status of a contractor resource (employee, vehicle or equipment) — Twind's way of managing access control exceptions in urgent or critical situations, outside the standard compliance evaluation.
Does a TA created in the app behave like one created on the web?
Yes. Same mandatory fields, same validation rules (including no overlaps per resource and site), same immediate effect on access status, and same notifications. The changelog records the origin as APP.
What happens when a TA is deleted?
The change takes effect immediately: the standard access control status is restored for all affected resources, regardless of the TA's original dates. The record remains available for audit.
Where do I find it in the app?
On the Home screen of the Access Control app, below the Visits section. The section is always visible for the relevant roles — no extra configuration or activation needed.
